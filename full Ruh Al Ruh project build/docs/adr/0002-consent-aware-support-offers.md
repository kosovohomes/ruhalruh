# Consent-aware support offers instead of automatic crisis override

Status: accepted

The source document specifies multilingual keyword detection that immediately replaces the assistant's reply with emergency resources. We instead detect risk signals and present a support offer that the Member can accept or decline. There is no automatic interception, third-party notification, or hidden risk score. Alternatives considered: the document's keyword override (rejected for false positives, negation failures and cultural mismatch) and a risk-scoring model (rejected because hidden scores conflict with member agency). Consequences: the project needs a reviewed, jurisdiction-aware resource directory and a multilingual safety evaluation set before launch.
